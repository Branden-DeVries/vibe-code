# 2048 Game - 6x6 Grid

A clone of the popular 2048 game with a 6x6 grid instead of the traditional 4x4.

## How to Play

1. Open `index.html` in your web browser
2. Use arrow keys to move tiles:
   - Arrow Up: Move tiles up
   - Arrow Down: Move tiles down
   - Arrow Left: Move tiles left
   - Arrow Right: Move tiles right
3. When two tiles with the same number touch, they merge into one
4. Try to create a tile with the number 2048!

## Features

- 6x6 game grid (larger than the traditional 4x4)
- Smooth animations
- Score tracking with best score saved in local storage
- Responsive design
- Win/lose detection
- New game functionality

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## Files

- `index.html` - Main game page
- `styles.css` - Game styling and animations
- `game.js` - Game logic and mechanics
